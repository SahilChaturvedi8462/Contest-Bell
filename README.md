# 🔔 ContestBell

> Never miss a competitive programming contest again.

ContestBell is a contest notification system that sends email alerts 
for upcoming competitive programming contests on platforms like 
Codeforces, CodeChef, LeetCode, AtCoder and more.

## ✨ Features

- 📧 Email notifications before contests start
- 🏆 Support for Codeforces, CodeChef, LeetCode, AtCoder
- 🎯 Subscribe to specific divisions (Div 1, Div 2, Div 3 etc.)
- 📅 Google Calendar integration will be in future..
- 🔐 Secure authentication with JWT
- ⏰ Automatic contest fetching every 6 hours

## 🛠️ Tech Stack

- **Backend** — Spring Boot (Java)
- **Database** — MongoDB Atlas
- **Email** — JavaMailSender + Gmail SMTP + Brevo email service
- **Auth** — JWT + Spring Security
- **Contest Data** — Codeforces API + clist.by
- **Deployment** — Railway / Render
